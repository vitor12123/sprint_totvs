# sprint_totvs

* Como usar *

  1. entre na pasta java
  2. faça esse caminho:
       com.sprint -> src -> main -> java/com.sprint2 -> IA -> Prompt.java
  3. no construtor pergunta mude o evento "reuniaoCompleta" para o id que vc deseja, que vão de 1 ate 1147
  4. rode o programa
  5. no navegador e digite:
       http://localhost:8080/chat
